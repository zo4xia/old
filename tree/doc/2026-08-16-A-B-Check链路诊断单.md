# A -> B -> Check 链路诊断单

日期：2026-08-16

## 结论

当前主链能走通，但还没有完全贴合项目本质。

产品不是课后答案生成器。B 要把一道题变成孩子能跟上的思考过程；Check 是第二双眼睛，负责口播润色和 TTS 适配，不能成为门槛。程序只接住内容和时间线，不该用轻微格式偏差拍死一整份教学稿。

## 已确认正常

- A -> B 会传题目文本、原图和网格后的完整画布截图。
- 原图与网格截图分别作为 `image_url` 发送，没有再被后端剔除。
- 网格截图在浏览器 Cache Storage 只保留最新 PNG，并在交接时回填 `previewDataUrl`。
- B 页面没有重复预览图。
- Check 返回格式异常时已回退 B 原表，不覆盖、不阻断 B。
- 四环一体、知识 callback、学段适配、固定开收场、中文数字口播、`[pause]` / `[excited]` / `[emphasis]` 已进入 B 与 Check 提示。

## 已证实问题

### P0：B 仍会被格式路障拍死

证据：`server/agentBV2Handler.js:76`、`src/agent-b-v2/contract.js:71`。

现状：模型多回 `notes`、旧 `答语`、第六字段，动作工具稍有偏差，或首行/分析行不完全符合约束，整表会回 `422`。

影响：可用的讲题稿会因程序格式问题被丢掉，违背“最小引导、最大兼容”。

修复方向：五字段继续作为画布载体，但服务端宽容提取 `rows`；忽略旧字段；不确定动作降级为 `[]`；保留可用口播和板书。不要新增内容校验或通过/失败闸门。

### P0：导出的 Markdown 不是可直接交给 TTS 的口播稿

证据：`src/lib/speechMarkdown.js:2`。

现状：导出包含 `# 口播稿`、题目、模型、导出时间。

影响：第三方 TTS 会把元数据一起读出来。

修复方向：只按当前行顺序导出 `speech`，行间空一行，原样保留 TTS 标签。文件名逻辑保留。

### P1：网格截图缺少用途标识

证据：`server/agentBV2Handler.js:48`。

现状：题目图和网格截图都发送给 B，但网格截图是裸 `image_url`。

影响：两张图同时存在时，B 不一定稳定理解第二张是布局依据。

修复方向：在网格截图前补一条文本说明“这是生成网格后的完整画布快照，用于看布局”。不改截图、坐标、A 逻辑或图片判断。

### P1：教学源与运行提示仍有旧格式残留

证据：`doc/建议提示.md:4,60,77,97`，`src/agent-b-v2/prompt.js:86,106`。

现状：仍有“七列执行表”、`【点击生成语音】`、`（停顿）`。

影响：长期教学源会把旧字段和旧 TTS 规则重新带回 B；`（停顿）` 不会被时间线识别为 `[pause]`，可能被 TTS 字面朗读。

修复方向：

- 七列改为五字段，并说明原 `notes` 教学意图进入 `speech` / `board`。
- 删除 `【点击生成语音】` 要求。
- 所有 `（停顿）` 改为 `[pause]`，不删任何教学示例和引导内容。
- 同步删除 `timing.js` 中针对旧标记的静默清洗。

### P1：自检脚本仍断言旧导出格式

证据：`server/proxySelfCheck.js:227`。

现状：自检仍要求 Markdown 含 `# 口播稿`。

影响：纯口播导出修复后，旧自检会产生假错并误导后续维护。

修复方向：随 Markdown 导出修复同步更新断言，检查纯 `speech` 与三种 TTS 标签保留即可。

### 发布前清理：测试 Key 在前端默认配置中

证据：`src/lib/checkAgentApiConfig.js:3`。

现状：按本机免费测试要求写入默认 Key。

影响：本机测试可用；任何提交、部署或分享前都必须清掉。

## Check 边界

- Check 是用户手动调用的第二次润色，不是审核、通过/失败机制。
- 它优先处理：中文数字口语、断句、TTS 标签、机械腔/产品说明腔、固定仪式和四环表达是否被压扁。
- 它拿不准或漏转时保留原句，不删内容、不留空、不挡表。
- 它不重做 A，不重排 B，不增加内容门槛；只在口播改动造成不同步时才碰 `board` 或 `actionSpec`。

## 禁止误修

- 不改 Agent A 识别、原图判断、知识库、布局、坐标和用户已确认的交接逻辑。
- 不再添加内容验证、题型门槛、必填知识点、必填图片或重复预览。
- 不把教学示例、儿童引导、问题链、错误预判、停顿和人味当作冗余删除。
- 不用 Check 替代 B 的完整第一次生成。

## 处理顺序

1. 让 B 的输出解析宽容化，拆掉整表 `422` 路障。
2. 修纯 `speech` Markdown 导出，并同步更新旧自检。
3. 给网格截图加用途文本标识。
4. 清教学源和运行提示的七列、旧点击标记、`（停顿）` 残留。
5. 发布前移除默认测试 Key。
