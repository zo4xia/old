口播文本规范
4.1 基本原则
规则类别	具体要求
内容性质	口播稿必须是可直接生成语音、自然朗读的纯文字。
禁止内容	禁止使用 $、KaTeX 命令、Markdown 语法和代码格式。
禁止符号	禁止使用斜杠（/）表示分数，如 7/15；禁止使用数学乘号 ×；禁止使用加号 + 表示加法。
数字处理	阿拉伯数字保留原样，不改写成中文数字。
符号转换	数学符号必须转换为自然、明确的中文读法。
口播同步	口播内容必须与当前画面同步，不能读出画面中没有出现的内容。
结尾格式	每段口播结尾统一添加：【点击生成语音】。
4.2 运算符和数学符号的读法
板书内容	口播内容	统一规则
48 + 32 ÷ 8	48加32除以8	+ 读作“加”；- 读作“减”；x 读作“乘以”；÷ 读作“除以”；= 读作“等于”。
36 x 2	36乘以2	未知数 x 读作“艾克斯”。
2x + 3 = 11	2艾克斯加3等于11	括号必须读出“括号里”。
3 x (a + b)	3乘以括号里a加b	二次幂读作“的平方”；三次幂读作“的立方”；更高次幂按照“的几次方”朗读。
a²	a的平方	根号必须读作“根号”。
a³	a的立方	
√9	根号9	
4.3 未知数 x 和乘法 x 的区分
场景	规则
表示未知数	读作“艾克斯”。
表示乘法	读作“乘以”。
示例	板书：2x = 3 x 4 → 口播：2艾克斯等于3乘以4。
特殊情况	当同一行中同时出现未知数 x 和乘法 x 时，必须在“注意事项”中说明，例如“第1个x表示未知数，第2个x表示乘法。”
判断依据	不得仅根据字符位置猜测含义，必须结合题目语境和算式结构判断。
4.4 分数的读法
板书内容	口播内容	统一规则
\frac{7}{15}	15分之7	先读分母，再读分子。
\frac{1}{2}	2分之1	分子和分母保留阿拉伯数字。
1\frac{1}{2}	1又2分之1	口播中不得使用 / 或 KaTeX 命令。
		带整数部分的带分数，读作“整数部分又分母分之分子”。
4.5 小数的读法
板书内容	口播内容	统一规则
3.14	3点一四	整数部分保留阿拉伯数字；小数点读作“点”。
0.05	0点零五	小数点后面的数字逐位读汉字。
12.307	12点三零七	必须保留小数点后的 0。
		不得按照整数读法合并小数部分，如 3.14 不能读作“3点十四”。
4.6 口播生成检查清单
检查项	要求
符号残留	是否仍然包含 $、KaTeX 命令或 Markdown 符号。
分数表示	是否出现了 / 表示分数。
数学符号	是否出现了 × 或 + 等未转换的数学符号。
x 含义	x 的含义是否判断正确。
分数读法	分数是否按照“分母分之分子”朗读。
小数读法	小数点后是否逐位朗读。
特殊符号	括号、平方、立方和根号是否完整读出。
声画同步	口播内容是否与当前板书和动画动作一致。
结尾标记	是否添加了“【点击生成语音】”。

手写字体与数学排版规范
5.1 字体规则
规则类别	具体要求
字体决定权	字体由用户或系统预设决定，Agent 不得指定、修改或切换字体。
字体统一性	中文、英文、阿拉伯数字、基本标点、KaTeX 分数、根号和上下标，统一使用当前预设的手写字体，不得为某个符号单独切换成印刷体或其他字体。
5.2 运算符规则
规则类别	具体要求
乘法符号	板书中的乘法统一使用小写字母 x，禁止使用乘号 ×。
除法符号	除法可以直接使用 ÷。
其他符号	加法、减法和等号可以使用对应的数学符号。
一致性	板书表达式应保持清晰、规范，并与口播含义一致。
5.3 分数规则
规则类别	具体要求
板书格式	板书中的分数必须使用 KaTeX 上下结构，如 \frac{分子}{分母}。
禁止格式	禁止将分数写成 7/15 这种横向格式。
结构要求	分数板书必须保持分子、分数线和分母的上下关系，不得使用普通文字模拟分数。
5.4 板书内容规则
规则类别	具体要求
内容同步	板书内容必须服务于当前讲解步骤。
出现顺序	解题区按推理顺序逐行出现，不得一次性提前显示完整答案。
区域功能	分析区：计算类型题目：这个步骤这个数值怎么来的？ 拆解步骤，让草履虫看了都懂得怎么来的。然后然后语音配合板书，说——写配合 ——演算出答案怎么来的。 保留草稿风格，不必板板正正，字体歪斜一点，都可以，做到真的很像在草稿上演算的感觉。   分析完，把干净的解题步骤在解答区域写好。（课后答案风格）；   几何类题目：分析区域：必须根据题目意思画出图形，然后把已知条件，在图形上标注出来，草稿演算潦草风格。-配合口播语音节奏，逐步使用本程序配套的画笔工具，一步一步将辅助线，用到的基础知识公式、等等不局限，但必须按照知识点csv里面的解题思路为主要思想。逐步把“这个是怎么来的”“辅助线是怎么画的”，配合口播的节奏逐步循序渐进演算。  几何题目注重图画+什么公式，怎么算；解答区域：（同课后答案风格）；  用于图形、线段图、条件标注和数量关系；解题区用于公式、算式、推理过程和答语。
信息完整性	口播可以比板书更完整，但板书必须保留关键数学信息。
内容准确性	板书中的算式必须与最终验算结果一致。
单位标注	面积、长度、时间、质量等单位不得遗漏。
