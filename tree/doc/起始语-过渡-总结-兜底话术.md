一、读题开头润色语
通用开场
• 读题 同学你好，很高兴为你讲解这道题。
• 读题 今天我们要讲解一组数学题，一共{题目数量}道。
• 读题 这些题目都是关于{题型描述}的，比如加法、减法运算。
• 读题（观察）我注意到这些题都是{特征描述}，都是两位数加减法。
• 读题 这组题目由易到难排列，前面几题比较简单，后面逐渐增加难度。
• 读题 通过这组题目，我们要掌握{核心知识点}的计算方法。
• 读题 我们以第一题为例进行详细讲解，其他题目用同样的方法。
• 读题 讲解完后，大家可以自己尝试剩下的题目，检验学习效果。
• 读题（观察）这组题目中，有些有括号，有些没有，要注意运算顺序的区别。
• 读题 仔细看这组题目，你发现了什么规律？有些数字是不是可以凑整简化计算啊。
• 读题 题目从简单到复杂，我们一步一步来，先掌握基础再挑战难题。

二、分类话术举例
通用分析
• 分析 通用这道题，我们来看一下：这道题目主要是_____(关联题型)，我们需要注意的是____(关联知识点)，下面我们一起看看怎么解题：
口算与估算
• 分析 口算要掌握心算技巧，比如凑十法、破十法。
• 分析 估算时先四舍五入，再计算近似值。
• 分析 记住25×4=100、125×8=1000这些特殊乘积。
竖式计算
• 分析 竖式计算首先要数位对齐，个位对个位，十位对十位。
• 分析 加法满十进一，减法退一当十，要记清楚。
• 分析 乘法竖式要注意部分积的写法，数位要对齐。
• 分析 除法竖式从高位除起，余数要比除数小。
运算顺序
• 分析 先算乘除，后算加减，有括号先算括号里面的。
• 分析 括号改变运算顺序，括号里的要先算。
• 分析 脱式计算要写递等式，等号要对齐，每步只算一个运算。
简便运算
• 分析 灵活运用加法交换律、结合律、乘法分配律等运算定律。
• 分析 观察数字特征，把能凑成整十、整百的数先结合。
• 分析 有些题目可以用拆分、合并等方法简化计算。
问题解决
• 分析 先理解题意，找出数量关系，再选择计算方法。
• 分析 复杂问题要分步解决，先求什么，再求什么。
• 分析 算完后要检验结果是否合理，是否符合实际情况。
三、环节过渡话术举例
开场→读题
• 开场→读题 下面我们来看具体的题目。
读题→分析
• 读题→分析 了解了题目，我们来分析一下解题思路。
• 读题→分析 看到题目，我们想一想这道题考察什么？
• 读题→分析 好的，现在我们分析一下这道题的解题要点。
分析→解答
• 分析→解答 知道了方法，现在我们来实际计算。
• 分析→解答 有了思路，我们动手算一算。
• 分析→解答 理论清楚了，接下来进行实际计算。
解答→总结
• 解答→总结 计算完成了，我们来总结一下这道题。
• 解答→总结 算出了答案，我们回顾一下解题过程。
• 解答→总结 答案出来了，我们总结一下学到的方法。
总结→结束
• 总结→结束 好了，这道题我们就将到这里。

四、总结话术示例
方法总结
• 方法概括 "我们用的方法是：先...再...最后..."
• 方法命名 "这种方法叫做{方法名称}，要记住。"
• 方法口诀 "记住口诀：{口诀内容}"
思路提炼
• 思路提炼 "解决这类问题的思路是：先分析数量关系，再列式计算。"
• 思路步骤 "遇到多步问题时，应该分三步：第一步...第二步...第三步..."
• 思路关键 "解题的关键是抓住{关键点}，其他问题迎刃而解。"
• 思路拓展 "除了这种思路，还可以从另一个角度思考..."
• 思路错误 "常见的错误思路是{错误思路}，我们要避免。"
易错提醒
• 易错强调 "这道题容易错的地方是{易错点}，要特别注意。"
• 错误类型 "常见的错误有{错误类型1}、{错误类型2}。"
• 防错方法 "避免错误的方法是{方法1}和{方法2}。"
• 检查要点 "算完后要检查{检查点1}和{检查点2}。"
• 错误纠正 "如果发现{错误}，应该{纠正方法}。"
规律总结
• 数字规律 "你发现了吗？这类题的数字有{规律描述}。"
• 运算规律 "混合运算的规律是：先乘除后加减，括号优先。"
• 题型规律 "这类题型的共同点是{特点1}和{特点2}。"
• 方法规律 "简便运算的规律：观察数字特征，运用运算定律。"
• 策略规律 "解决实际问题的规律：读题→分析→列式→计算→检验。"
