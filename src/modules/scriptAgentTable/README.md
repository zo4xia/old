# scriptAgentTable

`scriptAgentTable` owns the candidate rows editing layer for the script-board Agent.

Boundary:

- `rows` are candidate UI/editing state.
- `rows` are not a new formal TeachingProject asset.
- The only formal write path remains `rows -> compiler -> ScriptAgentDraft.spokenScript/boardPlan -> applyScriptAgentDraft() -> scriptText/boardLayout`.
- `<br>` and `<b>` are generated by the compiler, not hand-written by the Agent or user in rows mode.
